  # Weather Dashboard App

## Overview
A modern **Weather Dashboard** built with **React + TypeScript** that allows users to:

-  Search for any city worldwide  
-  View **current weather conditions** (temperature, humidity, wind speed, description)  
-  Toggle between **hourly and daily forecasts**  
-  Enjoy **dynamic animated weather icons**  
-  Experience a **dark, modern theme** with moving clouds and background effects  

---

## Features
- **Search Functionality:** Type a city name to get real-time weather data  
- **Animated Icons:** Real-time weather animations using [`react-animated-weather`](https://www.npmjs.com/package/react-animated-weather)  
- **Responsive Design:** Works seamlessly on mobile, tablet, and desktop  
- **Dark Theme UI:** Modern visuals using glassmorphism and background animations  
- **Environment Variables:** API key stored securely in `.env`  

---

## Completed Functionalities
- Current weather (temperature, humidity, wind speed, description)  
- Hourly forecast display  
- Daily forecast display  
- Dynamic weather icons (sun, clouds, rain, snow, etc.)  
- Background effects with moving clouds  
- Dark and modern theme  
- Mobile-friendly layout  
- City search with error handling (alerts for invalid cities)  
- Toggle between hourly and daily views  
- Secure API key handling via `.env`  

---

## Technologies Used
- **React + TypeScript**
- **Axios** — API calls
- **WeatherAPI** — weather data
- **React Animated Weather**
- **CSS** — glassmorphism, animations, dark theme
- **Vite** — fast build and dev server
